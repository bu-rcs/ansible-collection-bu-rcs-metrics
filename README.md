# bu_rcs.metrics

Ansible collection for the Prometheus/Grafana monitoring stack on the BU Shared
Computing Cluster.

To use this collection add following to galaxy-requirements.yml

```
collections:
  - name: bu_rcs.metrics
    type: git
    version: main
    source: https://github.com/bu-rcs/ansible-collection-bu-rcs-metrics.git
```
